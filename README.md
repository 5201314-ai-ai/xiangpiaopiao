# 香飘飘作品集网站

在线访问：https://5201314-ai-ai.github.io/xiangpiaopiao/

这是香飘飘的个人作品集网站，包含：

- 首页横幅：展示香飘飘的主视觉图片与自我介绍
- 作品相册：从本地相册上传照片，成为作品集的一部分
- 作品卡片：支持命名、写说明、点击查看大图、删除

## 怎么用

1. 双击打开 `index.html`，即可在浏览器中浏览网站。
2. 点击“上传照片”或中间的虚线提示框，从本地相册选择一张或多张图片。
3. 选一张时会弹出窗口让你给作品起名字、写一句话说明；选多张会直接添加。
4. 点击作品卡片可查看大图；鼠标悬停（手机上直接显示）卡片右上角的 × 可删除。

## 说明

- 上传的照片只保存在你当前浏览器的本地存储里，不会上传到任何服务器，换浏览器或清理浏览器数据后需要重新上传。
- 图片会在本地自动压缩后再保存，方便多传几张。
- 电脑、手机浏览器都可以使用。
